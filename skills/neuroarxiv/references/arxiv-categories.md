# arXiv category selection

Use the narrowest categories likely to contain the mechanism. Combine adjacent
categories only when they represent genuinely different research communities.
The authoritative taxonomy is <https://arxiv.org/category_taxonomy>.

## Common computing categories

| Category | Mechanisms commonly found there |
| --- | --- |
| `cs.AI` | agents, planning, knowledge representation |
| `cs.LG` | learning algorithms, model and training architecture |
| `cs.CL` | language models and text processing |
| `cs.CV` | visual perception and generation |
| `cs.IR` | search, ranking, recommendation, retrieval |
| `cs.DC` | distributed coordination, replication, scheduling |
| `cs.DB` | storage, indexing, queries, transactions, consistency |
| `cs.SE` | testing, program analysis, engineering methods |
| `cs.PL` | languages, types, compilers, runtimes |
| `cs.CR` | security, privacy, cryptographic protocols |
| `cs.NI` | networks, routing, congestion, edge systems |
| `cs.OS` | kernels, scheduling, memory, virtualization |
| `cs.HC` | interaction models and human factors |
| `cs.MA` | multi-Agent coordination and incentives |
| `cs.RO` | control, perception, planning, manipulation |
| `cs.DS` | data structures and algorithms |
| `cs.PF` | system performance and benchmarking |
