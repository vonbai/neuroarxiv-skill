# Preserve source-specific evidence roles

A Research Run combines Research Evidence from arXiv Papers with Documentation Evidence for concrete dependency questions when needed. These roles keep separate, typed Evidence Citations before contributing to one Recommended Path: Paper citations preserve the exact retrieved version, while Documentation Evidence citations preserve the declared version/source identity. Papers establish relevant prior art, mechanisms, evaluations, and reported limitations; version-specific documentation clarifies the intended use and constraints of dependencies already relevant to the path. Repository discovery and repository-quality assessment are outside the product scope.
